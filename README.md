# Tesot-bot

!Бот для прохожддения тестов (не рекомендуеться использовать на реальных тестах софт еще сухой)

Установка

1. Поставь Python 3.12 с https://python.org → галочка Add to PATH.

2. Сайт (import sys.txt → переименуй в app.py):
text

pip install flask
python app.py

→ http://127.0.0.1:8080

3. Бот (# -- coding utf-8 --.txt → переименуй в bot.py):
text

pip install pyautogui pillow requests keyboard
python bot.py

Рядом создай api.txt с ключом Gemini (https://aistudio.google.com/app/apikey). Браузер с тестом — на главном мониторе. СТАРТ / ESC.
